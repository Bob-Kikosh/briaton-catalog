# Briaton — каталог светильников

[English](README.md) | **Русский**

Страница каталога интернет-магазина освещения. Товары загружаются из JSON, их можно фильтровать, сортировать, листать по страницам и складывать в корзину. Всё написано на чистом JavaScript, без фреймворков.

## Что умеет страница

- **Каталог из данных.** Карточки строятся из `data/data.json`; рядом с каждым фильтром показано, сколько товаров этого типа.
- **Фильтры и сортировка.** Фильтр по типу светильника и по наличию, сортировка по цене и популярности, сброс одной кнопкой.
- **Город.** Выбранный город запоминается и влияет на фильтр «В наличии»: учитываются остатки именно в нём.
- **Пагинация.** По шесть товаров на странице; при смене фильтров список возвращается на первую.
- **Корзина.** Одинаковые товары складываются в одну строку со счётчиком, считается общая сумма, содержимое сохраняется в `localStorage`.
- **Слайдер «Товары дня»** на Swiper: количество карточек подстраивается под ширину экрана.
- **Подсказки** с остатками по городам на Tippy.js.
- **Форма заявки** с валидацией на JustValidate, отправкой через `fetch` и сообщением о результате.
- **Адаптив** для компьютера, планшета (до 1023px) и телефона (до 767px).
- **Доступность.** Меню, корзина и список городов закрываются по Escape и клику снаружи, у кнопок есть `aria-expanded` и подписи, фокус с клавиатуры виден.

## Технологии

- HTML5, БЭМ
- SCSS (модули `@use`, миксины для брейкпоинтов)
- JavaScript ES2022, нативные ES-модули
- [Swiper](https://swiperjs.com/), [Tippy.js](https://atomiks.github.io/tippyjs/), [JustValidate](https://just-validate.dev/) — подключены локально из `js/vendor`

## Запуск

Товары загружаются через `fetch`, поэтому страницу нужно открывать через локальный сервер, а не двойным кликом по файлу.

```bash
npm install
```

```bash
npm start
```

Сайт откроется на `http://localhost:3000`.

Сборка стилей после правок в SCSS:

```bash
npm run build
```

Пересборка при каждом сохранении:

```bash
npm run watch
```

## Как устроен код

Всё, от чего зависит список товаров, лежит в одном объекте состояния (`state.js`). Фильтры, сортировка, пагинация и выбор города только меняют это состояние и вызывают одну функцию `renderCatalog()`, которая заново фильтрует, сортирует и рисует список. Модули не знают друг о друге — их связывает `main.js`.

Корзина хранит пары «id товара — количество», а название и цену берёт из каталога, чтобы данные не расходились.

## О проекте

Учебный проект. Макет и исходная вёрстка взяты из курса, логика на JavaScript и адаптивная вёрстка — моя работа. Форма отправляет данные на тестовый сервис `httpbin.org`, настоящего сервера у проекта нет.
